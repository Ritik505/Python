#  Streamlit Login & Signup System (SQLite)

A modern and professional **Login + Signup Authentication System** built using **Streamlit + SQLite**.  
It includes a clean UI, secure password storage, session-based login, and a simple dashboard after authentication.

---

## ✨ Features

. Login system (Username + Password)  
. Signup / Register new users  
. SQLite database for storing users  
. Password hashing (SHA-256) for security  
. session-based authentication (Stay logged in)  
. Logout functionality  
. Validations:
- Email validation  
- Strong password check  
- Confirm password matching  
. Show/Hide password option  
. User Dashboard after login  
. CLI script to view database records

---

##  Tech Stack

- **Python**
- **Streamlit**
- **SQLite3**
- **Hashlib (Password Hashing)**
